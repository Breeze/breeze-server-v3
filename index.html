Breeze Server for .NET

Breeze is a library from IdeaBlade that helps you manage data in rich client applications. This site documents the .NET server-side packages, version 8.0.0, which target .NET 8, 9 and 10 on ASP.NET Core.

It has two halves: a hand-written Guide, and an API reference generated from the XML doc comments in breeze-server-v3. The API reference tab above reaches the whole of it; the table below starts at each package.

Packages

Package Namespace Purpose
Breeze.AspNetCore.NetCore Breeze.AspNetCore ASP.NET Core integration - [BreezeQueryFilter] and friends
Breeze.Persistence.EFCore Breeze.Persistence.EFCore Entity Framework Core support - start at EFPersistenceManager<T>
Breeze.Persistence.NH Breeze.Persistence.NH NHibernate support
Breeze.Persistence Breeze.Persistence Shared persistence layer - PersistenceManager
Breeze.Core Breeze.Core Query parsing and JSON serialization

A typical EF Core application installs the first two; the last two are pulled in automatically.

The reference is built from the net10.0 target. The public API is the same on net8.0 and net9.0, except that each target references the matching major version of Entity Framework Core.
