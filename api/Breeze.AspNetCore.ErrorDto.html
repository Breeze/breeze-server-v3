Remarks

IsReference = false keeps Newtonsoft's $id out of the document. The global settings turn on PreserveReferencesHandling.Objects and TypeNameHandling.Objects because entity payloads need $id/$ref for object graphs and $type for inheritance; an error document needs neither. $type still appears, since suppressing it for one type would take a custom converter - it is a harmless RFC 9457 extension member that a problem+json consumer ignores, but it does name the assembly.
