BuildIQueryableFunc(Type, MethodInfo)

Compile a delegate that calls a one-argument Queryable method on an untyped IQueryable.

public static Func<IQueryable, IQueryable> BuildIQueryableFunc(Type instanceType, MethodInfo method)

Parameters

instanceType Type

The element type to close the method over.

method MethodInfo

The Queryable method to call.

Returns

Func<IQueryable, IQueryable>

A delegate applying that method.

Remarks

The Queryable methods are generic, but the element type is only known at runtime, so the call is built as an expression - casting in to IQueryable<T> and back out again - and compiled.
