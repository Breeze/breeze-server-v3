Remarks

Each data type is a named singleton, declared as one of the static fields below. Constructing one registers it, so FromName(string) and FromType(Type) can find it afterwards. The names are part of the wire format - they are what the Breeze client writes into a query - so they cannot be changed without breaking clients.
