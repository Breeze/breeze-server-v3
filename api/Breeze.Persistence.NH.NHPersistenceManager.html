TypeFilter

Sets a function to filter types from metadata generation and SaveChanges. The function returns true if a Type should be included, false otherwise.

public Func<Type, bool>? TypeFilter { get; set; }

Property Value

Func<Type, bool>

Examples

// exclude the LogRecord entity MyNHContext.TypeFilter = (type) => type.Name != "LogRecord";

// exclude certain entities, and all Audit* entities var excluded = new string[] { "Comment", "LogRecord", "UserPermission" }; MyNHContext.TypeFilter = (type) => { if (excluded.Contains(type.Name)) return false; if (type.Name.StartsWith("Audit")) return false; return true; };

Persist the changes to the entities in the saveMap. This implements the abstract method in PersistenceManager.
