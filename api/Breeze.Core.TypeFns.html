GetMethodByExample<TIn1, TIn2, TOut>(Expression<Func<TIn1, TIn2, TOut>>, params Type[])

Find a two-argument method by writing an example call to it, then close it over different types.

public static MethodInfo GetMethodByExample<TIn1, TIn2, TOut>(Expression<Func<TIn1, TIn2, TOut>> prototypeLambda, params Type[] resolvedTypes)

Parameters

prototypeLambda Expression<Func<TIn1, TIn2, TOut>>

A lambda whose body is a call to the wanted method.

resolvedTypes Type[]

The type arguments to close the method over; none leaves it as found.

Returns

MethodInfo

The method, closed over resolvedTypes if it is generic.

Type Parameters

TIn1

First parameter type of the example call.

TIn2

Second parameter type of the example call.

TOut

Return type of the example call.

Remarks

Reflection over overloaded generic methods is awkward and easy to get wrong, so the method is named by a lambda that calls it - the compiler does the overload resolution - and the resulting definition is then re-closed over the types actually wanted.
