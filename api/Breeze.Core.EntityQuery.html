Remarks

A query is parsed from JSON by the EntityQuery(string?) constructor, checked against the entity type by Validate(Type), and then applied to an IQueryable by the extension methods in EntityQueryExtensions.

Every clause method returns a new query rather than changing this one, so a query can be safely shared and built on.
